Antes de guardar, en el MikroTik (API-SSL)

1. Certificado propio y servicio api-ssl, solo para la IP del servidor:

/certificate add name=ca-local common-name=ca-local key-usage=key-cert-sign,crl-sign /certificate sign ca-local /certificate add name=api-ssl common-name=api-ssl /certificate sign api-ssl ca=ca-local /ip service set api-ssl certificate=api-ssl port=8729 address=IP_DEL_SERVIDOR disabled=no

2. Un usuario solo para el sistema (no el admin ni el de MikroWisp):

/user group add name=django policy=read,write,api,!winbox,!web,!ssh,!ftp,!telnet /user add name=django-api group=django address=IP_DEL_SERVIDOR password=CLAVE_LARGA

3. (Opcional, más seguro) Copia la huella del certificado y pégala en Huella SHA-256:

/certificate print detail where name=api-ssl

Busca la línea fingerprint=. Con la huella guardada, el sistema solo se conecta a ese MikroTik; si el certificado cambia, se corta y te avisa.
